0.5| Punchcard: private, prepaid credits for autonomous agents that buy data services, built on Midnight.
8.5| Software agents now pay for each service call, one by one. But every paid call is linkable.
14| The provider sees which agent called what, and when. For an agent, that log is its strategy.
21.5| With Punchcard, an agent buys a bundle of calls once. The chain stores only a hiding commitment.
28.5| Each call is then paid with a zero knowledge proof: I own an unused credit, in some bundle, in this tree.
36| A nullifier stops double spending, and the server's request code is bound to the payment.
42| Public state lives in a historic Merkle tree, a set of nullifiers, and a ticket map.
48| The secret, the bundle size, and the Merkle path stay in the agent's private state, supplied as witnesses.
55| The circuit builds the commitment itself, checks the Merkle root, the use count, and the nullifier. Twenty one tests pass.
