Punchcard

An AI agent buys a bundle of API calls once, then pays every call with a zero-knowledge proof on Midnight. The API provider learns "this call was paid by a valid, unspent credit" — never which bundle, which buyer, or how many credits are left.
This page runs the compiled Compact contract in your browser (Midnight local simulator: same circuits and asserts). See the recorded Nov 6 run on the public Midnight preview network →
